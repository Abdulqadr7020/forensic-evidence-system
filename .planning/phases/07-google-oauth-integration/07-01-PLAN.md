# Plan 07-01: Google OAuth Provider Integration

## Requirements
- AUTH-02: Google OAuth

## Goal
Integrate Google OAuth provider authentication via Supabase into the application. Provide a helper to trigger Google OAuth with forced account selection, standard scopes, post-login URL sanitization, OAuth error handling in `AuthContext`, and an accessible UI trigger for verification.

## Context
- **Requirements Covered:** AUTH-02 (Google OAuth integration via Supabase)
- **Locked Decisions (from 07-CONTEXT.md):**
  - D-01: Dynamic `window.location.origin` as `redirectTo`.
  - D-02: Clean URL parameters via `window.history.replaceState` once session is established.
  - D-03: Capture callback errors (`error`, `error_description`) in `AuthContext` on mount and expose `authError` state.
  - D-04: Minimal inline loader during session exchange without blocking full-page UI.
  - D-05: Force account selection using `prompt: 'select_account'`.
  - D-06: Standard identity scopes (`email profile openid`).
  - D-07: Unified "Continue with Google" action for both sign-up and sign-in.
  - D-08: Open to all valid Google accounts.

## Implementation Steps

### 1. Implement Google OAuth in Auth Service
- [x] Edit `src/services/auth.ts`:
  - Implement and export `signInWithGoogle()`.
  - Configure `supabase.auth.signInWithOAuth` with:
    - `provider: 'google'`
    - `options.redirectTo`: `window.location.origin`
    - `options.queryParams`: `{ prompt: 'select_account' }`
    - `options.scopes`: `'email profile openid'`
  - Propagate errors if initiation fails.

### 2. Enhance AuthContext with Callback Handling & URL Cleanup
- [x] Edit `src/context/AuthContext.tsx`:
  - Extend `AuthContextType` with `authError: string | null`, `clearAuthError: () => void`, and `signInWithGoogle: () => Promise<void>`.
  - On mount, detect any OAuth callback error in URL parameters or hash fragments (e.g. `error_description`).
  - If tokens or hashes are present upon successful auth change, sanitize browser address bar with `window.history.replaceState(null, '', window.location.pathname)`.
  - Expose helper functions and error states to consumers of `useAuth()`.

### 3. Provide Verification UI & Google Auth Trigger
- [x] Update `src/App.tsx` (or top navigation/header `src/components/layout/Header.tsx`):
  - Add a "Continue with Google" action button styled with existing dark-mode design tokens.
  - Show minimal inline loading spinner when `loading` is active.
  - If `authError` occurs, render a clean error notice with dismiss action (`clearAuthError`).
  - If authenticated via Google or email, display user display name / email / avatar and a Sign Out button.

### 4. Build & Validation
- [x] Run `cmd.exe /c "npm run build"` to ensure full TypeScript compilation and bundling.
- [x] Verify that OAuth URL formation correctly targets Supabase OAuth endpoint with configured redirect and parameters.
