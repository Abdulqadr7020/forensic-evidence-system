# Conventions

**Analysis Date:** 2026-10-09

## Code Style
- **TypeScript:** Strict type checking enabled (`tsc --noEmit` in lint script).
- **React:** Functional components with Hooks.
- **Styling:** Utility-first using Tailwind CSS. `clsx` and `tailwind-merge` are used to conditionally apply classes safely.

## Naming
- **Components:** PascalCase (e.g. `DashboardView.tsx`).
- **Files/Folders:** kebab-case or PascalCase depending on exports, mostly lowercase for directories.
