# Phase 4 Context: Accessibility & Mobile Optimization

## User Preferences Captured
- **Mobile Navigation:** Hamburger menu with a sliding side drawer (standard).
- **Glassmorphism:** Maintain full glassmorphism (blurs and transparencies) on all devices.
- **Focus States:** Subtle inner glow matching the element's accent color (blends with design).

## Objectives
- Ensure the application is fully usable via keyboard (UI-05).
- Ensure contrast ratios are sufficient for text over glassmorphic elements.
- Implement responsive layout rules so grids and panels adapt cleanly to mobile sizes.

## Constraints & Considerations
- The `.planning/ROADMAP.md` indicates Phase 4 is for Accessibility and Mobile Optimization.
- The `MobileNav.tsx` already exists and uses a side drawer, but we need to ensure it's fully integrated and responsive.
- Focus states should use the inner glow preference rather than standard offset outlines.
