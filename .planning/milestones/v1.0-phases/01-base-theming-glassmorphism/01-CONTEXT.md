# Phase 1: Base Theming & Glassmorphism

## Domain
Establish the core visual language (dark mode, glass effects, typography).

## Canonical References
- None identified yet

## Code Context
- Tailwind CSS v4 is used for styling.
- `motion` will be used for animations.

## Decisions

### Background Style
- **Animation Behavior**: Both (Slow shift by default, reacts slightly to mouse)
- **Gradient Style**: Animated dark gradient (Highly premium, slowly shifting colors)

### Glassmorphism Intensity
- **Blur & Opacity**: Light blur, higher opacity (Subtle frosted effect, background shines through more)
- **Edge Definition**: Yes, add a subtle inner border (1px semi-transparent white/gray)

### Typography
- **Font Family**: Geometric Sans-Serif (e.g., Outfit, Poppins)
